Why korox

Quality checks that
respect your workflow.

Local First

Your code stays on your machine. Instant feedback with no network round trip.

Lightweight

Small binary, quick scans, and zero runtime overhead in your application.

Rust Native

Designed around Cargo and Rust idioms so it feels like part of the toolchain.

Actionable Diagnostics

Clear explanations and fixes, not noisy reports that slow down reviews.

Git Aware

Focus on changed files or scan the whole workspace when you need the full picture.

AI Optional

Use deterministic local rules by default. Add AI assistance only when it helps.

Built-in rules

Signal over noise.

Start with sensible defaults, then tune severity to match your team.

cargo-korox built-in rules
RuleLevelWhat it catches
unnecessary-clonewarnClones that can be replaced with a borrow
suspicious-unwrapwarnPotential panics from unchecked results
unused-variablesuggestionBindings that are never read
unnecessary-allocationwarnHeap allocations that add no value
inefficient-loopwarnLoops with a clearer or faster iterator
error-handlingerrorIgnored or poorly propagated errors
unnecessary-conversionsuggestionRedundant type conversions
collection-in-loopwarnCollections rebuilt inside a loop
inefficient-string-concatwarnRepeated string allocations while concatenating
redundant-clonewarnClones whose result is immediately discarded

Get running

From zero to useful
in a few commands.

Install from crates.io
cargo install cargo-korox
Build from source
git clone https://github.com/rahulpatle-sol/korox
cd korox
cargo install --path .
Verify install
cargo korox --version
# cargo-korox 0.1.0
Basic usage
cd your-rust-project
cargo korox check

Make it yours

Configuration
without ceremony.

Commit your policy with the project. Rules can be disabled, tuned, or promoted as your codebase grows.

korox.toml
# Project quality policy
[settings]
severity = "warn"

[rules]
unnecessary-clone = "warn"
suspicious-unwrap = "error"
unused-variable = "suggestion"
error-handling = "error"
inefficient-loop = "off"
error · blocks CI warn · review it suggestion · consider it

Ship with confidence

Quality checks
wherever you build.

.github/workflows/korox.yml
name: Korox
on: [push, pull_request]
jobs:
  quality:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: cargo install cargo-korox
      - run: cargo korox check --strict
.git/hooks/pre-commit
#!/usr/bin/env sh
set -e
cargo fmt -- --check
cargo korox check --changed
